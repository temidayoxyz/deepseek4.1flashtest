# Performance Running Sneaker — Procedural Build + Studio Renders

Everything here is generated by Python/`bpy` from scratch: no external models, no
textures, no image planes. Geometry is analytic (profile tables on a 21-point `u`
grid, `u` = 0 at the toe pole → 1 at the heel pole, `q` = 0/1 at the sole seam →
0.5 at the crest), materials are procedural node graphs driven by mesh UVs
measured in millimetres, and the studio is a light-grey cyclorama with a soft
key/fill/rim set.

## Deliverables

| File | What it is |
| --- | --- |
| `final_hero.png` | 2400×1350 hero: 3/4 lateral-front, slightly above centreline, lens 100 mm, 160 spp, denoised |
| `finalb_medial.png` | 1800×1010 extra angle: 3/4 medial-front |
| `finalb_frontlow.png` | 1800×1010 extra angle: low frontal (shows the toe bumper, lacing and tread) |
| `shoe_studio.blend` | Full scene: shoe + cyclorama + lights + camera, current render settings |
| `shoe.glb` | Shoe only (20 meshes, no studio), glTF 2.0 binary |

Design brief honoured: original design, no marks; off-white / charcoal / cool-grey
palette with small reflective silver accents; tapered toe box, engineered-knit
upper, layered overlays (quarter panel, eyestay, heel counter, toe rand),
padded collar, tongue, 6 evenly spaced eyelets per side, 3D criss-cross laces
with a tied bow, heel counter with reflective trim, heel pull tab, real stitch
dashes, sculpted foam midsole and a separate treaded rubber outsole.

## Reproduce

```powershell
cd sneaker
.\.venv\Scripts\python.exe main.py -- --res 2400x1350 --samples 160 --exposure -3.7 `
    --lens 100 --out final.png --save-blend shoe_studio.blend --glb shoe.glb `
    --views "36,19,1.00,hero"

.\.venv\Scripts\python.exe main.py -- --res 1800x1010 --samples 128 --exposure -3.7 `
    --lens 100 --out finalb.png --views "145,18,1.02,medial;70,11,1.06,frontlow"
```

Renders land next to the script (Blender's render CWD is `C:\`, so paths are
made absolute internally). Azimuth convention: 0° = +X lateral, 90° = toe,
180° = medial, 270° = heel.

## Module map

* `shoelib.py` — PCHIP/table maths, mesh builder (`MB`), `tube()`, `solidify()`, modifiers.
* `shoe.py` — the shoe: profile tables + `Last`, shell (analytic double wall), toe rand,
  midsole, outsole (two pads + tread), collar roll, tongue, liner, panels, eyestay,
  eyelets, laces + bow, pull tab, reflective trim, stitching.
* `materials.py` — procedural PBR: knit, dense-weave panel, foam, rubber, soft metal,
  collar, tongue, lace, thread.
* `studio.py` — cyclorama, lights, world, camera, render settings.
* `main.py` — CLI build + render + `.blend`/GLB export.
* `probe_*.py`, `check_profile.py`, `diag.py`, `measure.py` — geometry audits
  (strays, edge lengths, profile convergence, panel/tongue clearances, tip macros).

## Verification performed

* `check_profile.py` — profile tables converge to single points at both poles (spread 0.0000 mm).
* `probe_spike.py` / `probe_edges.py` / `probe_crest.py` — no stray vertices, no anomalous
  edges, nothing riding above the surface (only the bumper's intended proud offset).
* `probe_panel.py`, `probe_tongue.py` — panel outlines sane, tongue clears the shell wall (0 problems).
* Tip macros (`probe_tip_multi.py`) and identity-coloured passes (`probe_tint.py`) at 3 views.
* Hero histogram: max channel 255 only in ~15 sampled pixels (0.002 %), all tiny specular
  maxima on the metal eyelets/trim; no clipped areas on the shoe's body.
* `shoe.glb` header re-read (magic `glTF`, version 2, declared length = file length) and
  `shoe_studio.blend` re-opened (27 objects, 21 meshes, 14 materials).

## Accepted, deliberate details

* Interior is closed by a liner panel, not an anatomically modelled footbed (never visible).
* Panel edges are genuine cut edges (0.9–1.0 mm walls); at 3× zoom the bump-mapped edge
  reads slightly bound/scalloped — intentional "cut and bound overlay" look.
* The midsole→upper transition is a tangent discontinuity by design (two different materials).
* Hidden overlaps (tongue edge inside the shell wall, lace ends inside the collar tube,
  panel edges behind the foam flare) were verified not to poke through.
